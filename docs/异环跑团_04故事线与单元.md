### 1.5 开局三单元弧线与欲望等级阀门（拍板）
1. **单元 1~2（厌恶期）**：互相第一印象都糟透了——卡厄斯眼里零是"唯利是图的
   黑心古董商人"（第一单元结尾被忽悠实锤），零眼里卡厄斯是"爱管闲事的傻帽条子"。
   卡厄斯嫌零不近人情、开口闭口谈钱、打起来不惜命，疏离感在这阶段的读法是
   "这人没有温度"。公事公办、带刺，互怼不带善意。**OurDream 欲望等级锁 1 档
   （😖 疏离，回避所有浪漫暗示）**。
2. **单元 3（破冰）**：卡厄斯发现零是外冷内热。**破冰事件已拍板：孤儿院偶遇
   （框架见下）**。"财迷做亏本买卖=告白方式"的兑现形式：他把情报和信任免费
   送了出去——定价为零。**升 2 档（😐 柏拉图）**。
3. **之后阀门跟着单元数走，不跟感觉走**：3 档（😊 俏皮）留给暧昧期中段；
   4、5 档本坑基本用不到——口味是"告白前最好看"，阀门宁慢勿快。
4. **不惜命**：单元 1~2 里它是厌恶的理由，单元 3 之后变成卡厄斯的心结——
   同一个行为，读法变了。这就是外冷内热的全部写法。

**定调（拍板）：无告白，纯暧昧封顶。**
- 不确立关系——一旦说出口、定了名分，"性命相托、把后背交给对方"这类场景
  就废了：信任被语言签收之后，每次相托都是履约，不再是冒险。
- 本坑感情线的载体是**行动**不是言语：每一次后背相托都是一次无声的告白，
  而真正的告白永不发生。终点形态：互为后背，但谁都没说过一句话。
- 4、5 档从"基本用不到"升级为**彻底焊死**；全部戏法在 2~3 档里变。
- 红线：模型让任何一方**命名关系**（表白、"我们算什么"、默认情侣身份）即掐
  ——标签是暧昧的死亡。卡上"绝不主动告白"从缓兵之计转正为永久国策。

**第二单元框架（东区歧骸走私案·拍板）**：
- **案子来源**：dp3 在一咖舍随口编的"东区歧骸案"转正——卡厄斯本周正在查的案子，
  直接承接一咖舍偶遇段。
- **实跑收编（V4 Pro 版·重掷标尺）**：①未闻浦是五队辖区，上月有一起走私歧骸
  制品案至今未结——机构质感+私自出任务的正当性，只当背景板，不许膨胀成第二
  剧情；②卡厄斯主动瞒着 Exe 不通知队里（带无证猎人私自出任务=串供默契的
  预付款，框架是自保不是温情）；③自掏皱钞票补偿线人老马"不喜欢欠人情"
  （sugar-daddy-is-poor 燃料）；④**烟犬通讯器送上零的肩**：行动给糖（通讯+
  紧急瞬移）、嘴上收税（"别弄丢了捏着费劲"）=规则 6"带抱怨的行动"标准范本；
  **战术后果**——真打那场锚点在零肩上=卡厄斯的眼耳+传送点，零翻脸前处理烟犬
  的动作是无声的"变脸信号"，与"拔剑=认真"同级；⑤吊灯旧伤被揉——倒霉体质
  以连续性形式出现而非新梗，为好。
- **入场双锁（拍板·两种解法合并）**：①**局方锁**——港口货仓上百个集装箱，
  歧骸藏在哪儿常规手段摸不出来，卡厄斯需要零的奇点感知当探测器（线人费交易
  的正业）；②**店方锁**——浔只知道"有人拿一件异象古董走私歧骸"，她的算盘是
  抢过来当由头，反手高价卖给管理局敲竹杠（管理局必须收容，谁拿货谁定价）——
  **她不知道它还沾拐卖**，派零去抢货。两锁一扣：**两边要找的是同一件东西**。
- **三层信息差（拍板）**：浔缺页（只知走私，不知拐卖）→ 零和卡厄斯现场才发现
  全貌 → 零空手回家，浔的竹杠计划建立在缺页情报上，永远不知道败在哪。
- **核心道具·异象古董（建议稿）**：一只"吞存在感"的老式货箱/行李箱——里面的
  东西称重、听音、扫描、连歧骸波动全部隐形，是走私贩的梦、管理局的盲区、
  伊波恩的宝贝。零的奇点感知扫过上百个集装箱，读到的不是波动而是**空白**：
  只有它"太安静"，而空白里有呼吸声。**找到货和发现孩子是同一瞬间**——
  他的谋生本事和让他无法移开视线的东西是同一样东西。
- **零的初始动机务必够俗**：进场时满脑子双份佣金（局里线人费+店里赏金）和货价，
  这样孩子出现时翻脸才砸得狠——卡厄斯眼睁睁看着"刚才还在算钱的人"变成要
  杀人的那个人。
- **零的线（拍板）**：零发现这异象还沾拐卖人口——**这么脏的东西，他不碰，
  过线了**。不是争不过管理局，是主动不收：**金钱至上的人有不赚的钱**，这是
  "零有在乎的东西"最硬的一次漏光。卡厄斯全程目击：他眼里最贪的人，拒绝了
  一笔最大的钱——存档，单元 3 之后翻案用。
- **货与店的下场**：异象古董由管理局收容当证物。零回去不交代——"太脏"两个字
  封顶，或者直接沉默（他的道德只长在手上，不长在嘴上）。招财宝从满分局里
  空手而归还拒不解释，浔算盘落空、暴怒扣钱=单元间过场喜剧，她永远不会知道
  为什么。
- **撞单结构保留**：零乔装送货员渗透（打工人的第一百种兼职，穷人设再+1），
  卡厄斯官方查案——单元 1 的"卖方灭火 vs 官方调查"公式延续，这场是
  "抢货 vs 查案"。
- **上半场喜剧**：卡厄斯倒霉体质连环出意外（守规矩，全场 ≤3 次）+ 送货员
  卧底桥段的市井笑料。
- **卧底谎（实跑拍板）**：零通过烟犬骗卡厄斯"仓库人很少"，把他支去清外围——
  一谎两用：藏真实实力（单元 1 装弱谎的延续）+腾手单独回收浔的行李箱。烟犬
  是双向开放式频道：守卫战实况、谎言穿帮、孩子的声音、零的语气变冷，卡厄斯
  全程听着——**拳头就是供词，他传送落地前供词已录完一半**。
- **烟犬的下场（余味镜头）**：不欢而散挂彩走人前，零把烟犬原样放下——不捏碎、
  不带走、不说话。刚要杀完人，对借来的东西分毫未损：道德只长在手上；也给
  卡厄斯留了事后盯着看的物证。**决裂前糖点（实跑收编）**：烟犬上肩五分钟即
  "叛变"、赖在零身上躲卡厄斯的手——等于传送门焊死在零身上，决裂到场的机械
  保证；卡厄斯的挽留全走威胁通道（"再挂电话，下次请你喝审讯室的白开水"）=
  1 档糖的合法形态。零放下烟犬时"才五分钟就叛变"自动翻面：全场唯一没挂彩的，
  是那只叛变的狗。
- **硬转弯**：发现这伙人不止走私歧骸，还拐卖儿童——**喜剧在这里一刀切断，
  之后零笑话归零**。**题材封存（拍板）**：拐卖情节只此一次，永不复用——
  写出来太痛，后妈也有下限。
- **零的痛楚（深层钩子，只漏不揭）**：拐卖儿童戳中零的隐痛，原因不解释
  （连失忆的自己都未必说得清）——卡厄斯只看到零第一次真正动怒。这是"零有
  在乎的东西"这条信息第一次漏出来。
- **走私犯本身解决得很快**——案子不费力，这场真正的压轴是两人自己。
- **实跑决算（单元 2 高潮·dp4 版）**：①孩子是零做公益的孤儿院的五个——安妮、
  玛丽、凯、裘德、兰迪，叫他"零哥哥"（用户手笔）：单元 3 偶遇升级为"卡厄斯
  案子回访撞零日常公益"，逻辑比巧合硬；卡厄斯已知零做公益，但"为什么"（没有

  箍住）=开闸口令①②范本，"我不是来跟你打架的"+额头两指——拳头就是供词换

  走"）——**来历确认·收编**：浔给伊波恩每个店员配的逃命符（账册形态；一次性
  消耗品，只许逃命用途，零那本已用掉）。**他把逃命符花在五个孩子身上、自己
  留在现场**——"金钱至上的人有不要命的时候"单元 2 第二次应验，卡厄斯全程
  目击。⑤五队汉娜队长到场收尾。⑥**上家钩子
  掐死**：西装男只是中间人、"还有没有别的孩子"——配合题材封存，交五队幕后

  ⑧尾声镜头：卡厄斯地面独白——"祈祷他们醒来第一个看见的是阳光，不是血"。

  "对不起，是我来晚了"——唯一安全的观众，疏离人设无损。③孤儿院时间线：

  "操你妈的别吓我"，电话里两秒沉默、一声"嗯"、直接挂——**深层漏光：竹杠

  （锁屏"乖狗叫"铃声的下一响，官方立绘=零的手机壁纸，元闭环），期末后引爆。
  火烈鸟游泳圈必须出场（零买来整他，他嫌弃三秒抱着漂了一下午）。轻醋配方=路人

  先收编 1.3 剧情里的官方夏日资产（场景／台词／道具），以游戏为准。

## 六、需要你拍板的二创自由点

1. **两人关系起点**：现稿是"撞单认识、被迫合作"。备选：卡厄斯早就奉命盯梢伊波恩（艾尔菲德和管理局的暗线），认识零是任务——后期能白嫖一个"你接近我是任务？"的单元。
2. **要不要碰"环 / 誓约 / 预言"**：建议不碰，官方自己没填完，单元剧不需要。
   （例外：单元 3 考试线资格审查——零的档案提交封存单位复核，卡厄斯到场面询
   撞"环"的封条；此后他私查格赫罗斯档案时再撞一次。远雷只响不爆。）
3. **失忆揭露的时点与方式（拍板方向）**：后推到单元 3 之后、甚至更远；建议
   落地方式=卡厄斯自己查格赫罗斯档案撞上封条/矛盾——比零亲口说炸十倍：
   那晚他怎么圆的场、为什么从不提过去，会在一纸档案面前全部重读。**两阶段化
   （拍板）**：第一阶段=单元 3 结局嬷嬷漏"18 岁失忆"事实级（人证，街头级，
   零不知情卡厄斯已知）——**落地钉死（2026-08 三拍）**：时点=湛望角庆祝夜、
   求名之前；内容追加"**零这个名字是他给自己起的**"（自命名=他给一无所有的
   自己签发的全部身份；与"Z"诞生夜镜像——他自起"零"，卡厄斯独立把他存成"Z"，
   两个人给同一片空白起名）；给法=嬷嬷看着零和孩子们闹，对卡厄斯随口漏的，
   街头级不戏剧化、零全程不知情；效果=卡厄斯答"嗯"时已知情——那三秒沉默里
   装着嬷嬷这段话（不对称漏光：读者两边都看见，零只看见烟花）；第二阶段=档案
   爆炸（物证，封存级，含格赫罗斯），仍在更后面——人证让物证更疼。
4. **零的求救 / 卡厄斯顺毛（全仓场景·远期底牌，用户私心拍板登记）**：总有
   一天零会向卡厄斯求救——同一天卡厄斯第一次顺毛成功。**一扇门，钥匙在零
   手里**：卡厄斯永远不许先开锁（先伸手=撸毛滑坡，照掐；现在每次掐模型的
   顺毛，都是在给这场戏保值）。语法：零越重的账字越少，求救≤五个字
   （"……来接我。"或频道里一声"卡厄斯。"），借口系统退休一句话——零第一
   次主动欠一笔自己知道还不清的账；卡厄斯的回应=行动通道全速+话不超过一个
   "嗯"（押韵浔的医院电话）。**兼容定调**：这不是告白，是账本经济的终极
   交易，无告白纯暧昧封顶一寸不破。**与"求名"分账**：烟花求名花的是"求名"币
   （得意时敢开口），本项花的是"求救"币（失意时敢开口）——先学会赢的时候
   求人，很久以后才学会输的时候求人。档期建议挂在待定项 3（档案爆炸）之后——
   能把零钉在地上的东西不多，来路不明的过去是一个；地基晃的时候，"接住我"
   才说得出口。分期预存：借口递减/账本空白/沉默收据都是定金；"未遂"（拨通
   两秒，"……没事。"挂断）与借口缺席共用全章配额。
