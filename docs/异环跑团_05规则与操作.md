# 异环二创跑团设定库 05 · 规则与操作

> 项目：《异环 / Neverness to Everness》二创跑团——海特洛都市，双男主（零 × 卡厄斯），
> 无主线支线单元剧：日常吐槽 + 异象解决；吵架日常为主线，感情线慢热，**无告白纯暧昧封顶**。
> 分层策略：表层设定进 OurDream 卡 → 深层沉进记忆 → 跑熟合层喂 SillyTavern（迁移指南见 05）。
> 文档导航：**01 世界观与地图** ｜ **02 角色卡（OurDream 实操）** ｜ **03 角色设定（深层）** ｜ **04 故事线与单元** ｜ **05 规则与操作**
> 本分册：单元结构六拍、委托生成器、防崩守则、动作戏编排、SillyTavern 迁移指南。

---

### 1. 单元结构（六拍）
> **定位原则（拍板）**：单元剧主题要简单直白，一个单元 = 一天内的故事。
> **主线（拍板）**：吵架日常是主线，感情线是暗流——每个单元的燃料 =
> 一个不得不合作的案子 + 一个能吵起来的立场差；慢热阀门见 1.5。
1. **承接**：伊波恩日常开场（算盘声、委托板、塔吉多又闯祸），浔或艾尔菲德派单
2. **出发**：移动过程必须有市井插曲（10AM 广播、呗果热搜、路边歧骸）
3. **调查**：吐槽 + 三条线索（两真一假），零的奇点感知响一次
4. **扭曲**：委托人撒谎 / 异象升级 / ETD 介入——三选一，卡厄斯进入任务状态
5. **解决**：两人配合高光（烟雾 × 奇点感知的组合技是招牌）
6. **收尾**：回店结算 + 一句有余味的台词。恋爱线的砖全在这拍里搬。

### 2. 异象委托生成器（卡壳就掷 d6）

**① 委托人**
1. 半夜敲伊波恩门的歧骸老奶奶
2. 一咖舍老板（店里咖啡杯每天自己移位三厘米）
3. 塔吉多（恋爱危机第 N 季）
4. ETD 内部"友情转包"（Exe 一句话不说地把文件拍在卡厄斯桌上）
5. 娜娜莉强塞的"柯林斯家族地盘治安维护费抵用单"
6. 匿名委托——委托人就是异象本人

> 常驻轮换：王太太（见四点五 NPC 档）可替换任意一格——家里一屋子怪古董，
> 等于一屋子没引爆的委托。

**② 异象类型**
1. 附身型（物品成精，多半嘴碎）
2. 领域型（空间折叠 / 时间卡顿，奇点感知主场）
3. 情绪共振型（以某种强烈情绪为食，结案要解心结）
4. 拟态型（冒充熟人，喜剧与恐怖一线之隔）
5. 规则型（"必须遵守的怪规则"，破坏规则有代价）
6. 复合型，重掷两个缝一起

**③ 地点**
1. 半角街夜市  2. 桥间地后巷  3. 一咖舍  4. 末班电车站台
5. 照相馆"菲林轨迹"（重开营业，伊波恩全员折扣）  6. 月中夜晚才现身的当铺

**④ 麻烦升级（第 4 拍用）**
1. 委托人撒了关键谎
2. 异象其实是受害者，"解决"=帮它
3. 异象等级误判，实际高两级，ETD 要接管
4. 牵扯异能者罪犯——卡厄斯的烟雾兴奋起来了（罪业雷达）
5. 和零的记忆碎片有一丝丝关联（慎用，一个单元只给一片）
6. 最糟情况：以上两件同时发生

**彩蛋规则**：地点掷出"一咖舍"时，默认是零名下的门店——委托开在自家产业，
零得全程装作普通店员，卡厄斯夸"这店老板真大方"时零要面不改色地收下。

### 4. AI 防崩守则（跑出问题就往卡里补这几条）
> **模型切换备忘（2026-08-07）**：OurDream 模型 dp3 → DeepSeek V4 Pro。
> 可拆的工事：精分、全标签同时上班、梗当 KPI 复读——dp3 专属病，强模型能分场景
> 调用模式，OOC 纠偏频率大降；性格标签已升级为结构化三行版（见 02③，弱模型节食版存档备换）。**反而变大的风险**：① 道德护栏厚——
> 单元 2 就地正法场更可能拒演/说教，开闸口令从保险变刚需；② 升温从笨拙型变高明型——
> 它认得暧昧节拍，会主动铺 2 档+内容且写得好到舍不得删，巡逻从"抓跳档"改"抓渐变"，
> 收尾拍是重灾区；③ 爱推进剧情——会主动收伏笔、递和解台阶，单元 2 终点"不欢而散"
> 要守，看到台阶就删。
- 卡厄斯不许替零做决定、不许替零说话；NPC 再闹腾也不抢双人戏份。
- 卡厄斯只递刀不收刀：槽点可来自犯傻、莽撞、倒霉或"端不住"（③.5 新公式），
  语言 punchline 必须留给零；"成年人的物理吐槽"（揪领子、拎走、无视）允许。
  如果模型开始自己吐槽自己（精分式搞笑），说明跑偏了，重启该段。
- 每个单元 30~50 轮内收掉，收不掉就让卡厄斯说"先回店里，浔的算盘等不了了"。
- 倒霉梗每单元最多用三次，多了腻。
- 异象背后尽量有"人做的事"——罪业挂钩烟雾的设定是现成的主题钩子，日常喜剧底下垫一点点严肃，余味全在这。
- **信息视角偷跑（dp4 确诊）**：模型把用户叙述当共享场景知识——零只在叙述里
  透了维纳 501，卡厄斯第二句就杀到公寓门口。卡级治疗见 02④规则 7；犯了一次
  就 OOC"他不知道这个"并重掷，别心疼。
- **情感滑坡确诊（围着零/顺着零/撸毛）**：高明型升温不是跳档是渐变。通道分级：
  行动通道（带抱怨地办事/垫钱/背锅）1 档合法；陪伴通道（守着/跟着/远远看着）
  2 档+，1 档期出现即掐——创伤应急可豁免一次，且必须公事公办措辞（单元 2
  尾声医院扑空+烟犬远观已用掉这次豁免）。**收编自检：这条给它的温柔库存添货
  了吗？**它学卡厄斯的方式是复读收编过的模式；解药不是删糖，是喂配重（工作戏、
  吵架日常、立场差冲突、间章的垃圾话赛道）。

### 5. 动作戏编排
- **卡厄斯**：镰刀近战（大开大合、架势十足，是他耍帅的重灾区），一把枪远程
  辅助点射；烟雾塑形打配合——猎犬扑咬、缠绕、垫脚、挡刀，还能当传送锚点，
  日常滥用锚点是固定笑料（把猎犬留在一咖舍门口当"自家传送点"，被零吐槽）。
- **零**：近身格斗为主，日常带指虎，各种流派混着用（路数杂但很刁）；草十郎式
  战斗逻辑——出手淡淡的没有杀气，异象和对手都读不到他的起手，看着精瘦却是
  近战怪物[^84^][^86^]。旧单手剑（单边开刃）为辅；拔剑=认真的信号，一拔剑
  画风就该变（唯一例外是第一单元：那次拔剑是装弱演戏，见⑧）。
- **草十郎参考的边界**：借的是"无杀气"的战斗逻辑，不是性格——草十郎的白是
  山里长的，零的白是失忆擦出来的。草十郎的全力一击带自损属性，零是财迷、平时
  绝不做亏本买卖，"赔本的全力"留成全坑限定名场面，别日常化。
- **双打配合**：镰刀扫场烟雾控住，零钻进空当近身拆；枪远程点掉零够不着的漏
  网之鱼；烟雾垫脚送零上天、猎犬锁喉零补刀、烟雾墙挡流弹零在墙后算账。
  卡厄斯负责场面的花哨，零负责收尾的利落。
- **节奏**：动作戏里允许插科打诨（耍帅被拍飞照常发生），但第 4~5 拍高潮段
  两人必须都靠谱；战斗结束谁先开口谁吐槽。
- **深层限定（见⑦）**：烟雾异常浓烈=罪业读数爆表；第二条猎犬与「罪业清偿」
  全坑限定名场面，别用早。

## 五、跑完喂 SillyTavern：迁移指南

### 1. 字段映射
| OurDream | SillyTavern 角色卡 |
|---|---|
| Name / Tagline | name / creator_notes |
| 外观 prompt | 不进卡（出图用），可留 description 一行 |
| 性格标签 | personality（压缩成短句） |
| Backstory 全文 | description（设定部分）+ scenario（跑团规则部分） |
| 开场白 | first_mes 原样搬 |
| 对话示例 + 跑出来的精彩对话 | mes_example（`<START>` 分隔） |

### 2. 聊天记录怎么用（重点）
- **精选 3~5 段跑出来的好对话**（卡厄斯犯傻名场面、你的吐槽神来之笔、双人高光配合）塞进 mes_example，比任何形容词都管用。
- **已完结单元做成"委托档案"**，喂进 ST 世界书（Lorebook）：
  ```
  关键词：留声机 / 王太太 / 人头橱
  内容：第 01 号委托·已解决。三级附身型异象"夜话留声机"（半夜讲恐怖故事、
  近人显鬼影），浔昧良心高价卖给王太太惹出的民事纠纷。战中零持单手剑装弱、
  骗卡厄斯替他挡下鬼影攻击，自己暗中换指虎一击毙命；事后谎称"是另一只异象
  附着在留声机上、已被你清理"，留声机洗白、投诉失效，卡厄斯还以为自己救了
  人；零临场起意另敲王太太修理费一笔。销案复盘时卡厄斯才反应过来被骗，对零
  的初始印象：唯利是图的黑心古董商人。
  ```
  以后对话里一提到旧案，卡厄斯就"记得"，单元剧的连续性全靠这招。
- **世界书建议条目**：海特洛市、异象/歧骸/异能者、E.T.D 六队、伊波恩全员、零的隐藏资产（Draco / ST79 / 一咖舍 / 维纳 / 伊登，含"卡厄斯不知道"的揭示进度）、异象委托生成器（整表塞进去，ST 里也能掷）。
- **零**：做成 ST 的 User Persona，不要做第二张角色卡——双 AI 卡互演你会失去驾驶位。

### 3. 双平台手感差异预警
- 合层时机：OurDream 阶段卡里只有表层（dp3 时代是吃不动大设定；V4 Pro 能吃了，但表层卡已跑顺，不动）。喂 ST 时三层合一——本文档的深层储备（⑦、长期梗、零的深层）铺进 description / lorebook，OurDream 记忆里跑出来的沉淀筛一遍（留对的、改错的、删重复的）做成示例对话与委托档案。
- OurDream 倾向把角色往"伴侣"方向拽，恋爱线升温会比写的快；想维持慢热，跑的时候多用剧情压，别急着让它进入腻歪模式——这也是喂 ST 前最该筛掉的对话类型。
